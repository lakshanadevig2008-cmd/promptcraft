Core Elements Breakdown

              

                
                

                  

                    •
                  

                  

                    

                      1. Clear Task & Objective
                      25 pts
                    

                    Checks for direct action verbs and clear intent.
                  

                


                
                

                  

                    •
                  

                  

                    

                      2. Role / Expertise Persona
                      15 pts
                    

                    Checks for persona assignment ("Act as", "Expert in").
                  

                


                
                

                  

                    •
                  

                  

                    

                      3. Context & Background
                      15 pts
                    

                    Checks for domain context, circumstances, or project goals.
                  

                


                
                

                  

                    •
                  

                  

                    

                      4. Target Audience Identified
                      15 pts
                    

                    Checks whether the reader/receiver skill level is specified.
                  

                


                
                

                  

                    •
                  

                  

                    

                      5. Expected Output Format
                      15 pts
                    

                    Checks for formatting requests (bullets, tables, steps, code).
                  

                


                
                

                  

                    •
                  

                  

                    

                      6. Constraints & Guardrails
                      15 pts
                    

                    Checks for boundaries (length limits, exclusions, standards).
